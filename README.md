# irasutoya-prompt-app

いらすとや素材まわりの作業用ツール集です。どれも HTML ファイル 1 つで動きます（ダブルクリックでブラウザが開きます。インストール不要）。

| ファイル | 内容 |
|---|---|
| `sozai-tool.html` | **素材加工ツール**：いらすとや素材をフォルダごと読み込み、色補正・はみ出し修正をして、動画編集用の PNG に書き出す |
| `index.html` | 旧ツール：日本語から画像生成 AI 用の英語プロンプトを組み立てる（Google AI Studio 時代のもの） |

## 素材加工ツール（sozai-tool.html）

Chrome または Edge で開いてください。

**福笑いのように素材を重ねる（レイヤー）**
1. 左の一覧で顔のベースをクリック → 土台になります（動かないように🔒されます）
2. 目・眉・口・鼻をクリック → 上にレイヤーとして重なります
3. ドラッグで移動、角の□で大きさ、上の○で回転（Shiftで15°刻み）、F で左右反転、矢印キーで1px移動

- **フォルダ読み込み**：「フォルダを開く」でサブフォルダも含めて読み込み、「目」「口」などのフォルダ別に並びます。ドラッグでもOK。「前回のフォルダ」で開き直せます
- **デフォルト素材**：☆ で登録するとブラウザに保存され、次回もすぐ使えます。「フォルダから一括登録」も可
- **色補正**：選んだ素材レイヤーごとに、明るさ・コントラスト・彩度・色相・色温度
- **はみ出し修正**：スポイトで肌色を取ってペンで塗る。「＋ 塗りレイヤー」に塗れば後から塗りだけ消せます（下の絵からはみ出さない設定つき）。パーツ周りの余計な部分は消しゴムで透明に
- **書き出し**：完成画像を透過PNG／クロマキー緑／白、1〜4倍で保存。「レイヤーごとに保存」で位置をそろえた個別PNGも作れます（動画で口だけ差し替えるときなどに）
- 作業中の内容はブラウザに自動保存され、次回開くと復元されます

### ショートカット

| キー | 動作 |
|---|---|
| V / B / E / I / H | 移動 / ペン / 消しゴム / スポイト / 手のひら |
| 矢印（Shiftで10px） | 選んだレイヤーを動かす |
| F / Delete / Ctrl+D | 左右反転 / 削除 / 複製 |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直す |
| Ctrl+S | 完成画像を保存 |
| Space + ドラッグ、ホイール | 画面の移動・拡大縮小 |
| [ / ] | ブラシを細く / 太く |

素材の画像はパソコンの外へ送信されません（すべてブラウザ内で処理します）。
