# irasutoya-prompt-app

いらすとや素材まわりの作業用ツール集です。どれも HTML ファイル 1 つで動きます（ダブルクリックでブラウザが開きます。インストール不要）。

| ファイル | 内容 |
|---|---|
| `sozai-tool.html` | **素材加工ツール**：いらすとや素材をフォルダごと読み込み、色補正・はみ出し修正をして、動画編集用の PNG に書き出す |
| `index.html` | 旧ツール：日本語から画像生成 AI 用の英語プロンプトを組み立てる（Google AI Studio 時代のもの） |

## 素材加工ツール（sozai-tool.html）

Chrome または Edge で開いてください（フォルダの読み込み・保存先フォルダへの直接保存に対応しています）。

- **フォルダ読み込み**：「フォルダを開く」でサブフォルダも含めて全部読み込みます。フォルダを画面にドラッグしても OK。次回からは「前回のフォルダ」で開き直せます
- **デフォルト素材**：よく使う素材を ☆ で登録すると、ブラウザに保存されて次回もすぐ使えます。「フォルダから一括登録」でまとめて登録もできます
- **色補正**：明るさ・コントラスト・彩度・色相・色温度。今の補正を一覧の全素材にそろえることもできます
- **はみ出し修正**：スポイトで肌色を取ってペンでなぞります。「絵のある所だけ塗る」をオンにすると透明な外側には塗られません。消しゴムは透明にします。ペン圧対応
- **書き出し**：透過 PNG／クロマキー緑／白、1〜4 倍サイズ、ファイル名の頭・末尾を指定して保存。保存先フォルダを選べば直接保存します

### ショートカット

| キー | 動作 |
|---|---|
| B / E / I / H | ペン / 消しゴム / スポイト / 移動 |
| Alt + クリック | 一時的にスポイト |
| Space + ドラッグ、ホイール | 画面の移動・拡大縮小 |
| [ / ] | ブラシを細く / 太く |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直す |
| Ctrl+S | 保存 |
| ← → | 前後の素材へ |
| 0 / 1 | 全体表示 / 等倍表示 |

素材の画像はパソコンの外へ送信されません（すべてブラウザ内で処理します）。
